# Орфографический анализатор текста

Программа для проверки орфографии русского текста с возможностью автоматического и интерактивного исправления ошибок. Поддерживает работу с текстом из файла или вводом с клавиатуры, имеет светлую и тёмную темы.

## Особенности

- **Проверка орфографии** — выделение слов, отсутствующих в словаре, красной волнистой линией
- **Контекстные исправления** — клик по слову с ошибкой открывает меню с вариантами замены
- **Автоисправление** — кнопка «Исправить» автоматически заменяет все ошибки первым вариантом
- **Отмена изменений** — возможность вернуться к исходному тексту после проверки или исправлений
- **Поддержка файлов** — загрузка текста из .txt файлов с автоматической обработкой UTF-8
- **Смена темы** — светлая и тёмная темы оформления
- **Работа с буфером** — копирование текста и сохранение в файл
- **Горячие клавиши** — стандартные сочетания для работы с текстом

## Использование

### Запуск программы

После сборки и запуска программа выполнит:
1. Асинхронную загрузку словаря (около 1 секунды для ~200 000 слов)
2. Автоматический переход к основному интерфейсу после загрузки

### Основные действия

| Кнопка | Действие |
|--------|----------|
| **Проверить** | Запускает проверку орфографии всего текста |
| **Исправить** | Автоматически заменяет все найденные ошибки первым подходящим вариантом |
| **Отменить изменения** | Возвращает текст к состоянию до последней проверки или исправления |
| **Очистить** | Полностью очищает поле ввода |
| **Копировать** | Копирует текст в буфер обмена |
| **Сохранить** | Сохраняет текст в файл (.txt) |

### Интерактивное исправление

1. Нажмите **левой кнопкой мыши** на слово, подчёркнутое красным
2. В появившемся меню:
   - Выберите один из предложенных вариантов исправления
   - Или выберите **«Отметить как правильное»**, чтобы добавить слово в список игнорируемых

> ⚠️ Слова, добавленные в игнорируемые, запоминаются только на время сеанса работы программы.

### Источники текста

- **С клавиатуры** — текст вводится непосредственно в поле редактора
- **Из файла** — выбор текстового файла (.txt) с диска с последующей загрузкой

## Сборка проекта

### Требования

- **CMake** 3.10 или выше
- **Qt6** (Core, Widgets)
- Компилятор с поддержкой C++11 и выше

### Инструкция по сборке

```bash
# Клонирование репозитория (если ещё не сделали)
git clone https://github.com/AlexeyL54/spell_checker.git
cd SpellChecker

# Создание директории для сборки
mkdir build
cd build

# Конфигурация с CMake
cmake ..  

# Компиляция
make

# Запуск
./SpellChecker
```

> **Примечание:** Путь к словарю настроен на `../vocab/russian-words/russian.txt`. При необходимости измените путь в `MainWindow.cpp`.

## Алгоритм проверки орфографии

1. **Индексация триграмм** — для каждого слова в словаре строятся все возможные триграммы (перекрывающиеся последовательности из 3 символов) с маркерами начала и конца
2. **Поиск кандидатов** — из индекса выбираются слова, имеющие не менее 2 совпадающих триграмм
3. **Расстояние Левенштейна** — для кандидатов вычисляется минимальное количество операций вставки, удаления и замены
4. **Сортировка** — кандидаты сортируются по возрастанию расстояния и длине слова
5. **Результат** — возвращаются до 5 лучших вариантов исправления

## Инструкция пользователя

Программа имеет **встроенную инструкцию** — нажмите на кнопку с вопросительным знаком **«?»** в верхнем левом углу для получения подробной справочной информации.

### Горячие клавиши (стандартные для поля ввода)

| Сочетание | Действие |
|-----------|----------|
| `Ctrl+C` | Копировать выделенный текст |
| `Ctrl+X` | Вырезать выделенный текст |
| `Ctrl+V` | Вставить из буфера обмена |
| `Ctrl+Z` | Отменить последнее действие |
| `Ctrl+Y` | Повторить отменённое действие |
| `Ctrl+A` | Выделить весь текст |

## Тестирование

Проект включает модульные тесты для проверки работы:
- **Unistring** — класс для работы с UTF-8 строками
- **Vocabulary** — загрузка словаря и поиск исправлений

Запуск тестов:
```bash
cd tests/build
cmake ..
make
./unistring_test
./vocabulary_test
```
